# Architectural Decision Records

Los ADR registran decisiones de arquitectura que afectan limites, seguridad, datos u operacion. Las decisiones de arquitectura del MVP estan aceptadas; la seleccion concreta del proveedor OIDC permanece pospuesta dentro del ADR de identidad.

| ADR | Decision | Estado |
| --- | --- | --- |
| 0001 | Monolito modular Next.js y NestJS | Accepted |
| 0002 | Identidad de usuarios mediante OIDC | Accepted |
| 0003 | Broker MQTT y modelo de identidad de dispositivos | Accepted |
| 0004 | Contratos y validacion runtime | Accepted |
| 0005 | PostgreSQL y TimescaleDB para datos temporales | Accepted |
| 0006 | Realtime mediante WebSocket autorizado | Accepted |
| 0007 | Despliegue independiente y configuracion por entorno | Accepted |
